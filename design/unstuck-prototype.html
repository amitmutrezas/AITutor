Unstuck (working name) - lo-fi prototype not production code. Sample data throughout.

Stuck on a coding exercise? Get a hint, not the answer.

Unstuck gives you five levels of help on every exercise, from a gentle nudge to the full solution. You choose how much help you want, and you see the cost before you spend it.

1. Try it yourself

Write JavaScript in the browser. Your code runs against tests as you go.

2. Ask for the smallest hint

Nudge and Concept hints are free. Locate, Scaffold and Reveal use credits.

3. Finish without the answer

Most hints never show the solution, so you still do the thinking.

Count the vowels

Write countVowels(str) so it returns how many vowels (a, e, i, o, u) the string has. Uppercase vowels count too.

1  function countVowels(str) {
2    let count = 0;
3    for (const ch of str) {
4      if ("aeiou".includes(ch)) count++;5    }
6    return count;
7  }
